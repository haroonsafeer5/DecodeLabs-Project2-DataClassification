# Data Classification Using K-Nearest Neighbors (KNN) in C++

A lightweight C++ implementation of the K-Nearest Neighbors (KNN) supervised learning algorithm from scratch. Built as part of Project 2 during the DecodeLabs AI Internship.

## Overview
This project classifies data points using Euclidean Distance and majority voting logic without relying on external Machine Learning libraries.

## Key Features
- **Supervised Machine Learning:** Custom implementation of KNN logic.
- **Euclidean Distance:** Precise multi-dimensional distance calculations.
- **Custom Prediction Loop:** Automatic test classification and accuracy metric calculation.
